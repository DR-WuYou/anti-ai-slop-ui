# 颜色纪律

一句话：**颜色不是装饰，是信息**。界面显廉价，八成是颜色给多了。

## 1. 先只有灰

任何界面先用 8–12 级中性灰搭完，能看清层级再上色。灰度层级建议（冷灰，偏蓝 2%）：

```css
:root {
  --gray-0:  #ffffff;
  --gray-1:  #fbfbfc;
  --gray-2:  #f5f6f7;
  --gray-3:  #eceef0;
  --gray-4:  #e2e4e8;
  --gray-5:  #d3d6db;
  --gray-6:  #b9bec6;
  --gray-7:  #8f959f;
  --gray-8:  #6b717b;
  --gray-9:  #4a4f57;
  --gray-10: #2c3037;
  --gray-11: #16181c;
}
```

分配：背景 0–2、卡片 0、边框 4–5、次级文字 8、正文 10、标题 11。**不要用纯黑 #000 做正文**，它在屏幕上过重。

## 2. 一个强调色，最多两个语义色

```css
:root {
  --accent: #3b5bdb;        /* 品牌/主操作，一处足够 */
  --accent-hover: #2f4bc0;
  --danger: #c92a2a;
  --success: #2b8a3e;
}
```

- 强调色只出现在：主按钮、当前选中、关键状态、链接。别给标题、图标、背景都上色。
- 语义色用"文字 + 8% 底色"的组合，不要整块高饱和填充。
- 渐变只允许：同色相 2 档、亮度差 <8%、大尺寸背景。禁止紫→粉、蓝→紫、彩虹。

## 3. Radix Colors 的 12 阶怎么用

Radix 每个色有 12 阶，语义固定，直接按角色取：

| 阶 | 用途 |
| --- | --- |
| 1–2 | 页面背景、条纹背景 |
| 3–5 | 组件背景（默认 / hover / active） |
| 6–8 | 边框（6 弱 / 7 默认 / 8 hover） |
| 9–10 | 实心填充（按钮底） |
| 11–12 | 文字（11 次级 / 12 正文） |

暗色模式是另一套 12 阶，不要靠 `filter: invert` 或降低透明度硬转。

## 4. 对比度

- 正文 ≥ 4.5:1（WCAG AA），大字（≥24px 或 ≥19px 粗体）≥ 3:1。
- 占位符、禁用态可以低于 4.5，但要好认：不低于 3:1。
- 不要用颜色单独传达状态（红/绿），配图标或文字：`错误：邮箱格式不对`。

## 5. 暗色模式

```css
@media (prefers-color-scheme: dark) {
  :root {
    --bg: #0b0c0e;        /* 不是纯黑 */
    --surface: #141618;   /* 抬升一层 */
    --surface-2: #1b1e21;
    --border: #26292d;
    --text: #e9ecef;
    --text-dim: #a1a7ae;
  }
}
```

- 暗色里层级靠**亮度**，不靠阴影（阴影在暗底几乎不可见）。
- 强调色要提亮 10–15%，否则在暗底发闷。
- 纯黑 + 紫色光晕是最典型的 AI 暗色模板，直接避免。
