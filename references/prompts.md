# 30 条可以直接对 AI 说的话

复制即用。把 `[项目/页面]` 换掉，其余不用改。

## 开工前

1. 先别写代码。用三句话说明这个页面的用户是谁、唯一要完成的动作、最重要的信息。等我确认。
2. 先输出设计 token：圆角 3 档、间距 4/8 栅格、字号 4 级、一个强调色 + 12 级中性灰。之后所有组件只许用这些变量。
3. 用黑白灰先搭一版骨架，不要颜色、不要阴影、不要渐变。我确认结构后再上皮肤。
4. 这个页面只允许一个视觉重心。说出你选的是什么，为什么。

## 几何与细节

5. 所有圆角收敛到 6/10/16/999 四档，逐处替换，列出改前改后。
6. 内层圆角用 `inner = max(0, outer − padding)` 重算，把不一致的地方列出来。
7. 把所有 `border: 1px solid #...` 换成 `box-shadow: inset 0 0 0 0.5px rgb(0 0 0 / .12)`，并保留可交互元素的边界。
8. 卡片默认去掉阴影，只保留 hairline；阴影只留给浮层，用双层小扩散。
9. 检查所有圆形元素：只有真正的圆才用 `border-radius: 50%`，其它走圆角级数。
10. 图标统一 16/20 两个尺寸、统一描边宽度，emoji 全部替换掉。

## 排版

11. 字号收敛到 4 级，比例 1.2–1.33，其余用字重和灰度区分。
12. 中文正文行高 1.7，行宽 68ch；标题行高 1.25，加 `text-wrap: balance`。
13. 字体栈改成：西文字体在前，中文 `PingFang SC / Microsoft YaHei / Noto Sans SC` 在后，`sans-serif` 兜底。不要只写 Arial。
14. 去掉所有全大写 + 字距的小眉标，改成正常字重的小标签，或直接删。
15. 中文不要加 `letter-spacing`；全角标点统一，省略号用 `……`。
16. 表格数字用 `font-variant-numeric: tabular-nums` 并右对齐。

## 颜色

17. 背景只用黑白灰，颜色只给主操作、选中态和状态提示。
18. 删掉紫→粉渐变，改成一个强调色 + 中性底；强调色只出现在按钮和链接。
19. 把所有颜色换成 Radix Colors 的语义阶：背景 1–2、组件 3–5、边框 6–8、实心 9–10、文字 11–12。
20. 检查正文对比度 ≥ 4.5:1，大字 ≥ 3:1，把不达标的列出来。
21. 暗色模式不要纯黑 + 紫光：底色 #0B0C0E，抬升层用亮度，不用阴影。

## 间距与布局

22. 间距全部对齐到 4/8 栅格，组内 : 组间 ≥ 1:3，列出改动。
23. 正文左对齐，只有口号短句居中；卡片宽度按内容长度分栏，不要全部等高。
24. 首屏去掉三段式模板（大标题 + 副标题 + 双按钮 + 三 KPI），只留一个主张 + 一个动作。
25. 页面最大宽度 1200，长文 68ch；宽屏不要无限拉宽。

## 文案

26. 把"赋能 / 无缝 / 一键 / 重新定义"这类词删掉，换成具体动词 + 具体对象。
27. 按钮文案带上宾语：提交 → 保存草稿 / 发布到团队。
28. 空状态给出下一步，并且给一个可点的入口，不要写"暂无数据"。

## 动效与验收

29. 动效统一 120–200ms + `cubic-bezier(0.2, 0, 0, 1)`，只动 transform 和 opacity，删掉 `transition: all`。
30. 写完跑 `node scripts/audit.mjs .`，把低于 85 分的项逐条修到合格，并贴出前后分数。
